# Projet Nathalie Rives : refonte de nathalierives.com

Ce dossier est un projet distinct de Settle. La charte Settle du `CLAUDE.md`
racine (navy, amber, Sora, DM Sans…) ne s'applique PAS ici : le design vient
du brief de Nathalie Rives.

Quand l'utilisateur écrit « reprends » :

1. Lire `BRIEF.md` (fait foi), puis `JOURNAL.md`, puis `QUESTIONS.md`.
2. Continuer là où le journal s'arrête, sans refaire ce qui est fait.
3. Parler à l'utilisateur en français courant ; expliquer un terme technique
   en une phrase la première fois.

Règles de travail :

- Mettre à jour `JOURNAL.md` (où on en est, décisions et raisons, attentes,
  questions pour Nathalie, reste à faire) et `QUESTIONS.md` à chaque étape.
- Commit git à la fin de chaque étape, sur la branche
  `claude/nathalierives-redesign-syc71o`.
- Ne rien inventer (prix, dates, citations, parutions, clients, états,
  engagements) ; noter les manques pour Nathalie.
- Lecture seule sur le site en ligne ; aucun formulaire envoyé, aucun compte
  créé ; téléchargements lents.
- Cinq arrêts seulement (voir le brief) ; regrouper les questions pour
  l'arrêt suivant.
